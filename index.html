Drag a CSV file here, or choose one. It is read in your browser and never uploaded anywhere.

Columns read (names are case-insensitive, spaces or underscores): Name, Year, Number of Instances, Number of Attributes, Default Task, Data Types, Attribute Types, Sample size, and optionally Abstract and Datapage URL

Export from PostgreSQL with psql:

\copy (SELECT t.name, t.year, t.number_of_instances, t.number_of_attributes,
  t.default_task, t.data_types, t.attribute_types, d.abstract, d.datapage_url
  FROM public.uci_table t LEFT JOIN public.uci_database d ON d.name = t.name)
  TO 'uci.csv' WITH (FORMAT csv, HEADER true, ENCODING 'UTF8')
